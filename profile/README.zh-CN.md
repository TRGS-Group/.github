**TRGS 是一家横跨营销、人工智能与技术的跨学科工作室。**
我们让研究、设计、工程与增长共同参与思考，从最初的问题出发，直到构建出真正可用的系统。

我们的工作涵盖数字体验、人工智能应用、业务系统，以及将这些成果与人们的目标连接起来的策略。

### 四种视角，同一个不断适应的身份。

| | 为工作带来的价值 |
| :--- | :--- |
| **T · 技术** | 将想法转化为人们能够使用的产品、工具与系统。 |
| **R · 研究** | 审视假设、理解问题，找到可靠的方向。 |
| **G · 增长** | 连接我们构建的成果与企业触达用户、持续发展的方式。 |
| **S · 动态变量** | 解决方案、科学、工作室、策略、系统、主观能动性。形式随问题而定。 |

### 主观能动性

稳定的内核，灵活的方法。我们围绕问题所需整合不同领域的能力，同时对思考与执行负责。

最终的目的在人：让与我们合作的人拥有能力与自由，按照自己的意愿行动。
更好的系统，应当帮助你自主决策、创造并向前迈进。
