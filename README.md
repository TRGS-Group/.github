  Barlow typography and the website's blue, gold and violet palette.

Keep copy aligned with TRGS's multidisciplinary identity, current marketing/AI/
technology focus, and Subjective Initiative philosophy. The variable S is not a
fixed expansion. Use public website links; do not expose private repositories,

visibility or content of the organization's other repositories.

Keep English and Chinese copy in separate files; preserve the brand copy outside
those blocks. Never add private repository links to either public profile.
